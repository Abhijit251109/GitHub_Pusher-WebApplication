# GitHub Project Pusher 3.0.0

GitHub Project Pusher is now available as downloadable apps for Windows, macOS, and Android. Each app connects to the hosted service and uses the same GitHub account and cloud-saved project library as the website.

## Downloads

- [Windows x64 installer](./windows/GitHub-Project-Pusher-windows-x64.exe)
- [macOS Apple Silicon package](./macos/GitHub-Project-Pusher-macos-arm64.zip)
- [Android APK](./android/GitHub-Project-Pusher-android.apk)

## What's included

- Sign in with GitHub and access your cloud project library.
- Add projects, push changes, and sync with GitHub.
- Keep project files and safety snapshots in cloud storage.
- Access the same workspace from the website and supported native apps.

## Platform notes

- **Windows:** The x64 installer is not publisher-signed. Windows may show a SmartScreen or publisher warning.
- **macOS:** The package is for Apple Silicon Macs (arm64). Unzip it to get the DMG. The app is not notarized, so macOS may show a security warning.
- **Android:** The APK is debug-signed for testing and sideloading. Allow installation from your browser or file manager if prompted. It is not a Play Store release.

These apps require an internet connection and use the hosted GitHub Project Pusher service.
